The dbt MCP ↔ Snowflake gap closed on August 24, 2026 Registering the dbt MCP Server directly inside Snowflake's agent surface used to be blocked: Snowflake wanted a confidential OAuth client with a secret, dbt only ever issued public clients (PKCE). Snowflake shipped OAUTH_DYNAMIC_CLIENT support — a public client, matching what dbt already sends — so this now works natively. One caveat: it binds to one dbt platform host, so it's a single setup for a shared workshop account, or a live instructor demo if attendees are on individual trials.
